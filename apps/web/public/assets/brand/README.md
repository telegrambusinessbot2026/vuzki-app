# Brand Assets

This folder contains the core VUZKI brand visuals, which are centrally referenced via `brand.config.ts`. To change the logo globally across the app and website, replace these files while keeping the same names.

| File | Purpose | Recommended Size | Ratio | Format |
|------|---------|------------------|-------|--------|
| `logo-primary.svg` | Main application logo with text | scalable | — | SVG |
| `logo-dark.svg` | Variant optimized for dark backgrounds | scalable | — | SVG |
| `logo-light.svg` | Variant optimized for light backgrounds | scalable | — | SVG |
| `logo-mark.svg` | The VUZKI heart icon without text | scalable | 1:1 | SVG |
| `favicon.ico` | Browser tab icon | 32x32 | 1:1 | ICO |
| `app-icon.png` | PWA/Mobile home screen icon | 512x512 | 1:1 | PNG |

**Replacement Instructions:**
Do not rename the files. Simply overwrite them with your new brand assets.
All SVGs should use `currentColor` where appropriate or explicitly define brand colors if they are gradients.
