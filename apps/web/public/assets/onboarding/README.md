# Onboarding Assets

This folder contains the images used during the new user onboarding and welcome flows (e.g. Next/Skip screens, introductory tutorials).

| File | Purpose | Recommended Size | Ratio | Format |
|------|---------|------------------|-------|--------|
| `onboarding-01.webp` | First intro screen / welcome | 1080×1920 | 9:16 | WEBP |
| `onboarding-02.webp` | Second feature highlight | 1080×1920 | 9:16 | WEBP |
| `onboarding-03.webp` | Third feature highlight | 1080×1920 | 9:16 | WEBP |
| `onboarding-04.webp` | Final / 'Get Started' screen | 1080×1920 | 9:16 | WEBP |

**Replacement Instructions:**
To change the onboarding slides, overwrite these files. For best performance, optimize the images and save them as WebP format. The UI expects a vertical, mobile-friendly aspect ratio (9:16).
