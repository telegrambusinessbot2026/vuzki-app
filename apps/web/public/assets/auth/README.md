# Auth Assets

This folder contains the visual elements used in the Login, Registration, and Forgot Password screens.

| File | Purpose | Recommended Size | Ratio | Format |
|------|---------|------------------|-------|--------|
| `auth-bg.webp` | Full-screen background image | 1920×1080 | 16:9 | WEBP |
| `auth-illustration.webp` | Thematic illustration | 800×800 | 1:1 | WEBP |

**Replacement Instructions:**
Overwrite these files to update the authentication backgrounds and illustrations. For dark mode compatibility, ensure images have appropriate contrast or include alpha transparency for illustrations.
